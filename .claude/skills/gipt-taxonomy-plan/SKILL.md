# gipt-taxonomy-plan

## 목적

목표 수량을 기존 사이트 taxonomy와 한국어 검색 수요에 맞춰 균형 있게 분배한다.

## 기본 100개 분배안

| 영역 | 권장 개수 |
|---|---:|
| 광고 키비주얼 | 12 |
| 제품 상세·커머스 | 12 |
| 카드뉴스·SNS | 10 |
| 인포그래픽 | 10 |
| 포스터 | 10 |
| 캐릭터·마스코트 | 8 |
| UI·앱 목업 | 8 |
| 패션·룩북 | 8 |
| 음식·카페 | 8 |
| 건축·공간 | 7 |
| 교육·설명형 | 7 |

## 규칙

- 기존 slug를 우선 사용한다.
- 한 카테고리가 전체의 15%를 넘지 않게 한다.
- 같은 제품/장면/스타일 조합은 중복으로 보지 않도록 topic seed를 관리한다.
- 각 seed는 title, category, domains, format, tags, intendedUse를 포함한다.

## 확장 전략

- 100개: 사이트 대표성과 검색 다양성 확보
- 300개: 각 카테고리의 실전 사용 맥락 세분화
- 500개: 산업별·포맷별 long-tail 확장
- 1000개: RAG 검색용 coverage 중심 확장
